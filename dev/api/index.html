API

The group element

DihedralGroups.Dihedral — Type
Dihedral{d} <: Any

Dihedral group element representing a symmetry of a regular d-sided polygon.

Fields

  • phi::Int: Rotation component (0 ≤ phi < d)
  • reflect::Bool: Reflection flag (true for reflection elements)

Mathematical Representation

  • Pure rotations: rᵏ where k = phi
  • With reflections: rᵏ s where k = phi and s sends 0 to d-1

Group Structure

The dihedral group D_d has order 2d with presentation: ⟨ r, s | rᵈ = s² = id, srs = r⁻¹ ⟩

Examples

julia> Dihedral{4}(1, false)  # 90° rotation
D4: r^1

julia> Dihedral{4}(0, true)   # Pure reflection
D4: s

Generators

DihedralGroups.r — Function
r(d, phi = 1) -> Dihedral{d}

The rotation generator of D_d, and the constructor for any rotation element.

r(d) is the generator r itself: a single counterclockwise step of 360°/d. r(d, phi) is rᵖʰⁱ, a rotation by phi steps, reduced modulo d.

Examples

julia> r(4)
D4: r^1

julia> r(4, 3)      # three steps, i.e. 270°
D4: r^3

julia> r(4, 5)      # reduced modulo d
D4: r^1

julia> r(4, 1)^2
D4: r^2

See also

  • s — the reflection generator.
  • dhrotation — the equivalent constructor.
source
DihedralGroups.s — Function
s(d, phi = 0) -> Dihedral{d}

The reflection generator of D_d, and the constructor for any reflection element.

s(d) is the reflection s itself: it fixes vertex 0 and sends vertex i to d - i. s(d, phi) is rᵖʰⁱ·s, that same reflection precomposed with a rotation by phi steps.

Every reflection is its own inverse, so s(d, phi)^2 == one(Dihedral{d}).

Examples

julia> s(4)
D4: s

julia> s(4, 1)
D4: r^1·s

julia> s(4, 1)^2
D4: Id

julia> 0^s(5)       # s fixes vertex 0
0

See also

  • r — the rotation generator.
  • dhreflect — the equivalent constructor.

Group operations

These extend the corresponding Base functions, so they are listed under their Base names. The signature must be written to match the method exactly: {d} appears below wherever the method itself is declared with where {d}, and is absent for one(g::Dihedral), which is not.

Base.:* — Method
g::Dihedral{d} * h::Dihedral{d} -> Dihedral{d}

Group multiplication operation.

g * h applies g first and then h. Written out on the vertices, that makes the action a left action:

\[(i^g)^h = i^{g * h}\]

Composition Rules

rᵃ * rᵇ = rᵃ⁺ᵇ rᵃ * (rᵇ s) = rᵇ⁻ᵃ s (rᵃ s) * rᵇ = rᵃ⁺ᵇ s (rᵃ s) * (rᵇ s) = rᵇ⁻ᵃ

Examples

julia> r(4) * s(4)  # A quarter turn, then a reflection
D4: r^3·s

julia> s(4) * r(4)  # A reflection, then a quarter turn
D4: r^1·s
source
Base.inv — Method
inv(g::Dihedral{d}) -> Dihedral{d}

Group inverse element.

Inverse Rules

(rᵏ)⁻¹ = rᵈ⁻ᵏ (rᵏ s)⁻¹ = rᵏ s

Examples

julia> inv(r(5, 2))  # Inverse of 144° rotation
D5: r^3

julia> inv(s(4))     # Reflection is self-inverse
D4: s
source
Base.:^ — Method
g::Dihedral{d} ^ n::Int -> Dihedral{d}

Group element exponentiation.

Algorithm

  1. Compute element order m = order(g)
  2. Reduce exponent modulo order: n_red = n mod m
  3. Compute gⁿ_ʳᵉᵈ by repeated multiplication

Examples

julia> r(4, 1)^4  # Full rotation cycle
D4: Id

julia> s(3)^2      # Reflection squared
D3: Id
source
Base.:^ — Method
i::Int ^ g::Dihedral{d} -> Int

Group action on polygon vertices.

Action Rules

Pure rotation: i ↦ (i + k) mod d Reflection: i ↦ (d - i + k) mod d

This is a left action: (i^g)^h == i^(g * h).

Arguments

  • i: Vertex index (0 to d-1)
  • g: Group element

Examples

julia> 1^r(4, 1)  # Rotate vertex 1 by 90°
2

julia> 3^s(5)     # Reflect vertex 3
2

DihedralGroups.order — Function
order(g::Dihedral{d}) -> Int

Element order (smallest k > 0 where gᵏ = identity).

Order Calculation

Identity: 1 Pure rotation: d / gcd(k, d) Reflection: 2

Examples

julia> order(r(8, 2))  # 90° rotation in octagon
4

julia> order(dhreflect(5, 0))
2

Iteration

DihedralGroups.dihedralgroup — Function
dihedralgroup(d) -> DihedralGroup{d}

Construct the iterator over all 2d elements of D_d (d ≥ 1).

The rotations r⁰ … rᵈ⁻¹ come first, then the reflections r⁰s … rᵈ⁻¹s.

Throws an ArgumentError if d < 1.

Examples

julia> collect(dihedralgroup(3))
6-element Vector{Dihedral{3}}:
 D3: Id
 D3: r^1
 D3: r^2
 D3: s
 D3: r^1·s
 D3: r^2·s

julia> length(dihedralgroup(5))
10

See also

  • DihedralGroup — the iterator type this returns.

DihedralGroups.DihedralGroup — Type
DihedralGroup{d}

The iterator type over all 2d elements of the dihedral group D_d, as returned by dihedralgroup.

DihedralGroup is not exported; construct one with dihedralgroup(d).

Element order

  1. Rotations: r⁰, r¹, ..., rᵈ⁻¹
  2. Reflections: r⁰s, r¹s, ..., rᵈ⁻¹s

Examples

julia> collect(dihedralgroup(3))
6-element Vector{Dihedral{3}}:
 D3: Id
 D3: r^1
 D3: r^2
 D3: s
 D3: r^1·s
 D3: r^2·s

julia> length(dihedralgroup(3))
6
